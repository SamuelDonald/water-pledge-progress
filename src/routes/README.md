# Application Routes

This application uses TanStack file-based routing. Each route file in this directory defines a URL.

## NavalHomes routes

| File | URL |
| --- | --- |
| `index.tsx` | `/` |
| `properties.$slug.tsx` | `/properties/:slug` |
| `__root.tsx` | Application shell |

`routeTree.gen.ts` is generated by TanStack Router. Do not edit it manually; the router tooling regenerates it from the route files.
